# Opptra Discount Engine & Checkout Portal

**Live Deployment:** https://discount-engine-assignment-a9i8.vercel.app/

Customer-facing cart pricing engine built for the **Opptra FDE Intern (Central Tech)** challenge. Evaluates non-stackable maximum-saving rules, stacks `stackable: true` offers, applies post-item cart-level thresholds, and supports decoupled Natural Language rule creation and PDF invoice ingestion.
